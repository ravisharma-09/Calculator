# Calculator Neo

Calculator Neo is a neo brutalism inspired calculator built using HTML, CSS, and JavaScript.

It includes:
- Basic calculator operations
- AI mode using Math.js API
- Dark / Light mode
- Responsive design
- Black and white brutalist UI

## Inspiration

I wanted to create a calculator with a different visual style instead of a typical modern UI.  
This project was also an opportunity to learn API integration and build a smart calculator mode.
